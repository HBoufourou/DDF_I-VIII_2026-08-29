# Guide de dépôt Zenodo — Corpus DDF v1.0
### Un seul enregistrement pour les huit articles · à faire ce soir

## Les étapes, dans l'ordre

1. **Overleaf d'abord (15 min)** : remplacer les .tex de III, IV, V, VII par
   ceux du paquet → recompiler → exporter les 4 PDF → les substituer dans le
   dossier. (Détail au CHANGELOG.)
2. zenodo.org → Upload → New upload.
3. Téléverser **tous les fichiers du paquet en vrac** (pas le zip) : les PDF
   restent prévisualisables, les scripts et données téléchargeables un à un.
4. Remplir les métadonnées (bloc prêt ci-dessous).
5. « Reserve DOI » avant publication — le DOI de concept versionnera la
   v1.1 (ajout de IX) et la v2 (réécriture) sans changer de citation.
6. Publier. Noter le DOI.
7. Après publication : reporter le DOI dans le bloc de traçabilité lors de
   la v1.1 — pas besoin de retoucher ce soir.

classification de Fano et ses deux classes vides, la fenêtre 4–6 GeV, la
baryogenèse par winding — tous horodatés **avant** les résultats LHCb et

aucun) ni la v2 (réécriture unique, après les verdicts).
